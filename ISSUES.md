# Reporting problems

Use the [GitHub issue tracker](https://github.com/mstan/MegaManX5Recomp/issues)
for reproducible software problems. Include the release version, stage, hero
assignments, relevant mod settings and clear reproduction steps.

Input Display and Recording is enabled in Mods by default. Preserve useful
local diagnostics, but do not upload disc images, extracted game data or
personal files. See [the co-op guide](docs/COOP_GUIDE.md#reporting-problems).
