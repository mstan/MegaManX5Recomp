# Playing Mega Man X5 together

## Starting a game

Co-op is enabled by default. Assign separate devices in the launcher's controller
setup, then press PLAY. Player 1 selects a hero and available armor; Player 2
selects a form of the remaining hero. One player is X and the other is Zero.
Normal and unlocked alternate forms appear as separate choices. The optional
armor codes in Mods make the corresponding forms available without changing
saved campaign unlock progress.

## Cameras, menus and doors

The launcher's controller setup has a Configure button for each player. Use it
to map that player's keyboard or selected controller. In X5's Options > Button
Configuration, press Select to switch between Player One and Player Two, then
assign that player's seven action buttons. Either controller can edit Player
Two's assignments. Save campaign progress to retain both layouts on the native
memory card.

Side-by-side is the default local display. Each pane follows its own hero and
shows that hero's life meter. Unified view and online camera choices are in
Mods. Either player may press Start for their own pause menu; the player who
opened it controls the menu.

Either-player doors gather the partner when one hero enters. Both-player entry
waits for the living pair. Keep the default Skip Alia Hints option enabled for
uninterrupted stage traversal. If you enable hints, their shared scenes retain
the original partner-gathering behavior.

Player 2 can hold Select to withdraw, then release and press Select to request
a safe rejoin near Player 1. This is unavailable during forced Ride Chaser play.

## Playing online

Use Host/Join in the launcher. Both peers must use the same release, disc
revision and compatible gameplay mod choices. Each peer assigns their local
input device; the room assigns the gameplay seat. The host selects the shared
co-op rules. Local split-screen and online camera layout have separate settings.

Windows x64 and Linux x64 each use their own native execution profile. Both
peers must run the exact same platform executable; profiles do not authorize
cross-platform or cross-build play. The session settles one common supported
profile before the first game frame and keeps it fixed for the match.

## Progress and settings

The pair shares one campaign and its rewards. Use the game's SAVE and LOAD with
native memory cards for persistent progress. Back up saves/ before moving an
installation, and keep your launcher settings when updating.

Save states are build-specific snapshots. They are useful within the same build
and mod setup, but are not a replacement for a native save across releases.

The Mods page includes camera layout, door entry, tank contents, armor codes and
rendering options. Changes to co-op options require a fresh game boot.

## Reporting problems

Gameplay Input Recording is enabled by default and can be disabled in Mods.
That saved choice applies offline and online. Input Display is a separate
optional control and starts off.
Keep the relevant local diagnostic recording if you find a problem. Include the
release version, stage, hero assignments, what happened and what you expected.
Never upload your disc image, extracted game code or personal files publicly.
