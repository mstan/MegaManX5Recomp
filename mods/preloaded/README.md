# Preloaded Mega Man X5 mods

This catalog contains default-on game-owned enhancements:

- `mmx5.enhancement.widescreen` — modern adaptive Custom Renderer, with
  authored map tiles, room-edge framing and ordinary enemy placement.
- `mmx5.enhancement.resident-loading` — resident blocking DAT/BIN transfers
  through original receive callbacks and GPU/sound upload queues.

- `mmx5.enhancement.skip-alia` - skips automatic Alia stage hints before
  they freeze play. On by default in solo/local co-op, fixed on in netplay;
  story, boss and capsule dialogue stays native.

These are exposed in the launcher's **Mods** view. Interpolation is archived,
uncompiled and unavailable, as are generic CD/host pacing options. The title's
sprite/tile renderer uses nearest textures and 1080p internal rendering.
