# Preloaded Mega Man X5 mods

This catalog contains exactly two game-owned, default-disabled presentation
enhancements:

- `mmx5.enhancement.widescreen` — game-specific 16:9 field-of-view expansion.
- `mmx5.enhancement.frame-interpolation` — presentation-only interpolation at
  the display refresh rate or a selected fixed output rate.

Both are exposed in the launcher's **Mods** view. They replace the older generic
Settings controls so each enhancement has one owner and one opt-in switch.
Neither changes the player's save format, and neither is enabled by default.
